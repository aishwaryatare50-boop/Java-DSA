## 🛠️ Prerequisites

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd <repo-name>
   ```

2. **Compile a Java file**
   ```bash
   javac FileName.java
   ```

3. **Run the compiled class**
   ```bash
   java FileName
   ```
